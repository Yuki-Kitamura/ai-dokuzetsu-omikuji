# AdSense 設定メモ

## サイト審査（所有権の確認）

「サイトの審査が必要です」と表示されたら、**確認方法で「メタタグ」を選択**してください。

1. AdSense で **「メタタグ」** を選ぶ
2. 表示されたコードの **`content="..."` の中身だけ**（長い英数字）をコピー
3. 次のように設定する:
   - **ローカル**: `.env.local` に  
     `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION=ここにコピーした長い英数字`
   - **Vercel**: プロジェクト → Settings → Environment Variables に  
     `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` = コピーした長い英数字
4. **必ずデプロイし直す**
   - Vercel: 環境変数を保存したあと、**Deployments** から **「Redeploy」** を実行する（「再デプロイしないとメタタグが反映されません」）
   - ローカル: `npm run dev` を一度止めてから再起動
5. デプロイ完了後、**ブラウザで本番URLを開き「ページのソースを表示」** し、`google-site-verification` を検索して `<meta name="google-site-verification" content="...">` が含まれているか確認する
6. メタタグがソースに見えたら、AdSense で **「確認」** をクリック

**「サイトの所有権を確認できませんでした」と出る場合**
- 環境変数を追加した**あと**に **Redeploy しているか** 確認する（変数だけ追加で再デプロイしていないと、古いビルドのままなのでメタタグが出ません）
- 本番URL（例: https://ai-dokuzetsu-omikuji.vercel.app）を開き、右クリック → **「ページのソースを表示」** で `google-site-verification` を検索する。見つからなければ、Vercel の Environment Variables に `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` が入っているか、Redeploy したかを見直す
- **別の方法を試す**: AdSense で「**ads.txt スニペット**」を選んだ場合、表示された1行（例: `google.com, pub-xxxxxxxxxx, DIRECT, xxxxx`）をコピーし、プロジェクトの **`public/ads.txt`** にその1行だけを保存してデプロイする。すると `https://あなたのドメイン/ads.txt` でその内容が表示され、AdSense が確認できる

このプロジェクトでは `app/layout.tsx` の `<head>` で上記の環境変数を読み、`<meta name="google-site-verification" content="...">` を出力しています。

# AdSense スロット（広告ユニット）の設定方法

スロットIDは、**広告ユニット**を作成すると発行されます。  
管理画面の構成は時期で変わるため、次のどちらかの経路を探してください。

---

## 左メニューに「広告」「サイト」が出ていない場合

左メニューに **ホーム / レポート / アカウント / フィードバック** しかない場合、**「広告」や「サイト」は表示されていない**状態です。よくあるパターンです。

### 試すこと

1. **画面左上の ≡（ハンバーガーメニュー）** をクリック  
   → メニューが開いたら **「サイト」** や **「広告」** がないか確認する。

2. **「ホーム」を開いた状態で、メインエリアを確認**  
   → 「サイトを追加」「コードを取得」「広告を設定」などのリンクやカードが出ていないか見る。  
   → サイトを追加する導線から、のちに「広告」メニューが有効になることがあります。

3. **審査通過直後・アカウントが新しい**  
   → 「広告ユニットを作成」や「サイトごとの設定」は、**サイトが承認され、しばらく経ってから**表示されることがあります。数日〜1週間後に再度ログインして左メニューを確認する。

### この状態でもできること

- **クライアントID（ca-pub-xxx）だけ**取得できていれば、その値を `NEXT_PUBLIC_ADSENSE_CLIENT_ID` に設定済みで問題ありません。
- **スロットID** は「広告ユニット」を作成しないと出ません。今は **スロット用のメニューが出ていない** ため、**スロットは後回し**でよいです。
- このアプリでは、スロット未設定のときは **「ここに広告が入ります（ダミー）」** と表示されます。  
  「広告」や「サイト」メニューが表示されるようになったら、下記の手順A/Bで広告ユニットを作成し、取得したスロットIDを `NEXT_PUBLIC_ADSENSE_SLOT_BANNER` に設定すれば、同じ位置に実広告が表示されます。

---

## 手順A: 「広告」から辿る場合

1. [Google AdSense](https://www.google.com/adsense/) にログイン
2. **左メニュー**で **「広告」** をクリック
3. **「広告ユニットごと」**（または「広告ユニット」）をクリック
4. **「ディスプレイ広告」** を選ぶ、または **「新しい広告ユニット」** / **「広告ユニットを作成」** のようなボタンをクリック
5. 表示された画面で:
   - **名前**: 管理用（例: 「画面下部バナー」）
   - **広告サイズ**: **「レスポンシブ」** のまま（推奨）
6. **「作成」** または **「保存してコードを取得」** をクリック
7. 表示されたコードの中の **`data-ad-slot="1234567890"`** の **数字部分** がスロットIDです。  
   → これを `.env.local` の `NEXT_PUBLIC_ADSENSE_SLOT_BANNER` に設定します。

---

## 手順B: 「サイト」から辿る場合（サイト別管理の画面）

1. AdSense にログイン
2. **左メニュー**で **「サイト」**（または「ウェブサイト」）をクリック
3. 表示されている **対象のサイト（ドメイン）** をクリック
4. サイトの詳細画面で **「広告」** や **「広告ユニット」** のタブ／リンクをクリック
5. **「新しい広告ユニットを作成」** や **「広告を追加」** などのボタンを探してクリック
6. 広告タイプで **「ディスプレイ広告」** を選び、名前とサイズ（レスポンシブ推奨）を設定
7. 作成後、表示されるコードの **`data-ad-slot="数字"`** の数字がスロットIDです。

---

## スロットIDの使い方（このプロジェクト）

- **クライアントID**（`ca-pub-xxxxx`）は、AdSense の「コードをコピー」の script の `client=` の値です。  
  → `NEXT_PUBLIC_ADSENSE_CLIENT_ID` に設定済みならそのままでOKです。

- **スロットID**は、上記で作成した広告ユニットのコードに含まれる `data-ad-slot` の値です。  
  → `.env.local` に次のように追加します:

```env
NEXT_PUBLIC_ADSENSE_SLOT_BANNER=ここにスロットIDの数字だけ
```

例: `data-ad-slot="1234567890"` なら  
`NEXT_PUBLIC_ADSENSE_SLOT_BANNER=1234567890`

---

## スロット作成画面が見つからない場合

- **「広告の設定」** → **「広告ユニット」** というメニューがない場合、**「収益化」** や **「広告」** の下のサブメニューを開いて、**「広告ユニット」** / **「手動で広告を配置」** を探してください。
- 審査通過直後や、**自動広告だけ**のアカウントでは、広告ユニット作成が表示されないことがあります。その場合は **「広告」** または **「サイト」** の項目が増えていないか、数日後に再度確認してください。
- どうしても見つからない場合は、[AdSense ヘルプ「ディスプレイ広告ユニットを作成する」](https://support.google.com/adsense/answer/9274025?hl=ja) や、画面右上の **?** ヘルプ内で「広告ユニット」を検索すると、現在の画面に合わせた案内が出ます。

---

## スロットがなくても表示されるようにする場合

**クライアントIDだけ**設定している状態では、このアプリでは意図的に「スロット未設定ならダミー表示」にしています。  
AdSense の **自動広告** だけを使う場合は、サイトに貼る **script タグ（client=ca-pub-xxx）だけ** 入れればよく、広告ユニット（スロット）は必須ではありません。  
ただし、**画面上の「ここに広告が入る」位置に確実に1本出す**には、上記のとおり **ディスプレイ広告ユニットを1つ作成してスロットIDを取得**し、`NEXT_PUBLIC_ADSENSE_SLOT_BANNER` に設定するのが確実です。
